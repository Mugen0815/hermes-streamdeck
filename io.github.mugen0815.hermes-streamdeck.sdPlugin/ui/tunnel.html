SSH tunnel (all keys)

A press starts ssh -N -L to the SSH host, another press stops it. Login must work with an SSH key and without a password prompt. Best set the host up as an alias in ~/.ssh/config (user, key file). The local port must match the Hermes URL.

A tunnel you started yourself outside Stream Deck is shown as "External" and is not stopped.
